## 🎯 What Is This?

**AI Resume Screener** is a full-stack web application that uses
Groq AI (LLaMA 3 70B) to automatically screen and rank job
applicants based on their resumes and a given job description.

No more manually reading through dozens of resumes.
Just paste the job description, upload resumes, and get
AI-powered rankings in seconds.

---

## ✨ Features

- 🔍 Screen multiple resumes at once
- 📊 AI scores each resume from 0 to 100
- 🏆 Automatically ranks candidates best to worst
- 📝 Detailed summary for every candidate
- ✅ Shows strengths and ❌ gaps per resume
- 💡 Skills matched highlighted
- 🎯 Recommendation: Strongly Recommend / Recommend / Maybe / Reject
- ⚡ Results in 3 to 8 seconds (powered by Groq)
